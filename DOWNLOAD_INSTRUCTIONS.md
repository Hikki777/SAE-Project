## 🚀 Descargar Instaladores

### Opción 1: Instalador para Windows (RECOMENDADO)
**Archivo:** `SAE - Sistema de Administración Educativa Setup 1.0.7.exe`  
**Tamaño:** ~180 MB  
**Ubicación:** `release/` → `SAE - Sistema de Administración Educativa Setup 1.0.7.exe`

**Ventajas:**
- ✅ Instalación automática
- ✅ Acceso directo en Inicio
- ✅ Desinstalación fácil
- ✅ Configuración automática

**Pasos:**
1. Descargar el archivo `.exe`
2. Hacer doble clic para ejecutar
3. Seguir el asistente de instalación
4. Seleccionar carpeta de destino (recomendado: C:\Program Files\)
5. ¡Listo! El programa se abrirá automáticamente

---

### Opción 2: Portable (Versión sin Instalación)
**Archivo:** `SAE-v1.0.7-Portable.zip`  
**Tamaño:** ~200 MB  
**Ubicación:** `release/` → `SAE-v1.0.7-Portable.zip`

**Ventajas:**
- ✅ Sin instalación requerida
- ✅ Portátil en USB
- ✅ No contamina registro de Windows
- ✅ Múltiples versiones simultáneamente

**Pasos:**
1. Descargar el archivo `.zip`
2. Descompactar en la carpeta deseada
3. Abrir la carpeta descompactada

5. ¡Listo! El programa se abrirá inmediatamente

## 📋 Requisitos del Sistema

**Mínimos:**
- Windows 10 (64-bit) o superior
- 500 MB de espacio libre en disco
- 4 GB de RAM (recomendado 8 GB)
- Conexión a internet (solo para primera sincronización)

**Recomendado:**
- Windows 11 (64-bit)
- 1 GB de espacio libre
- 8 GB de RAM
- SSD para mejor rendimiento

## 🔍 Verificar Descarga

Para verificar que el archivo se descargó correctamente:

### Windows
```powershell
# Abrir PowerShell en la carpeta donde descargaste el archivo
certUtil -hashfile "SAE - Sistema de Administración Educativa Setup 1.0.7.exe" SHA256
```

El hash debe coincidir con el publicado en GitHub.

## 🆘 Solucionar Problemas de Descarga

### Si el archivo no se descarga
1. Verificar conexión a internet
2. Intentar con otro navegador
3. Desactivar antivirus temporalmente (algunos bloquean descargas)
4. Descargar desde GitHub Releases (opción más segura)

### Si la descarga es lenta
1. Descargar en horas con menos tráfico
2. Usar software de descarga acelerada
3. Intentar desde WiFi más rápido

### Si el archivo está corrupto
1. Eliminar el archivo descargado
2. Limpiar caché del navegador
3. Volver a descargar
4. Verificar espacio libre en disco

## 🚀 Pasos Post-Instalación

Después de instalar o descompactar:

1. **Primera ejecución**
   - Esperar a que se cargue la interfaz
   - Permitir acceso a red (si pregunta)
   - La base de datos se inicializará automáticamente

2. **Configuración Inicial**
   - Ir a Configuración → Institución
   - Completar datos de tu institución
   - Seleccionar el sistema educativo

3. **Crear Administrador**
   - Ir a Usuarios
   - Crear cuenta de administrador
   - Usar esa cuenta para acceder

4. **Importar Datos** (opcional)
   - Usar importador de estudiantes
   - Cargar docentes
   - Configurar jornadas y grados

## ❓ Preguntas Frecuentes

**P: ¿Puedo usar ambas versiones (instalador y portable) al mismo tiempo?**  
R: Sí, son independientes. Pueden coexistir en el mismo computador.

**P: ¿Los datos se sincronizaban entre versiones?**  
R: No, cada instalación tiene su propia base de datos.

**P: ¿Puedo copiar la carpeta portable a otro USB?**  
R: Sí, funciona en cualquier computadora con Windows 10+.

**P: ¿Necesito desinstalar versiones anteriores antes de instalar v1.0.7?**  
R: No es requerido, pero se recomienda para evitar conflictos.

**P: ¿Dónde se guardan los datos?**  
R: Instalador: `C:\Users\[Usuario]\AppData` | Portable: Misma carpeta del ejecutable
