# SAE v1.1.2 — Release Notes

**Fecha de release:** 2026-04-13  
**Tipo:** Estabilización y Pulido de UX  
**Estado:** Estable en Producción

---

## 🛡️ Estabilización Crítica de Backups

### Restauración de Archivos Binarios (v2.0)
- **Eliminación del Error 400:** Se ha migrado el envío de archivos de backup de `axios` a `native fetch`. Esto garantiza que los navegadores modernos y Electron gestionen correctamente el `boundary` multipart/form-data, que anteriormente se perdía debido a los interceptores de axios en subidas de gran tamaño.
- **UX de Restauración:** Se eliminó la lógica de seguridad de "múltiple clic". Ahora, una vez ingresada la contraseña, el sistema procesa la restauración al primer clic, bloqueando el botón con un estado de carga animado para evitar duplicados.

---

## 🕒 Sincronización Horaria Robusta

### Verificación de Tiempo de Internet
- **Failover a API secundaria:** El sistema ahora consulta `worldtimeapi.org` como fuente primaria. Si esta falla, se bloquea o tiene lentitud, el sistema cambia automáticamente a `timeapi.io`.
- **Gestión de Latencia:** Se aumentó el timeout de consulta a 10 segundos para dar soporte a redes escolares saturadas o con firewalls estrictos.
- **Modo Silencioso:** Se eliminaron las advertencias técnicas en consola durante fallos de sincronización; el sistema ahora usa la hora local de forma transparente como último recurso.

---

## 🎨 Refinamiento Visual y de Identidad

### Avatares de Género en Vistas de Detalle
- **Integración de `GenderAvatar`**: Los modales de "Vista Previa" (cuando se hace clic en la foto de una persona) ya no muestran un icono de usuario genérico.
- **Identidad Dinámica**: Si un Alumno o Personal no tiene una fotografía cargada, el sistema genera automáticamente una ilustración basada en su sexo registrado, manteniendo la coherencia visual con el resto de la aplicación.
- **Ajustes en Modales**: Se optimizó el tamaño y relleno de los contenedores de fotos en los paneles de Personal y Alumnos para mejor visualización de los avatares.
