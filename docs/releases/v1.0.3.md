# Release v1.0.3

**Fecha**: 2026-02-03

## 🔧 Correcciones Críticas del Instalador

### Solucionado
- **[CRÍTICO]** Corregido punto de entrada en `package.json` de `backend/server.js` a `electron/main.js`. La aplicación ahora se ejecuta correctamente después de la instalación y crea las ventanas apropiadamente en modo producción.
- **[CRÍTICO]** Implementado inicio automático del backend en modo producción. `electron/main.js` ahora inicia `backend/server.js` automáticamente cuando está empaquetado. Se agregó health check para esperar a que el backend esté listo antes de mostrar la interfaz en `http://localhost:5000`.
- **[IMPORTANTE]** Agregada página de licencia GPL-3.0 al instalador para que los usuarios puedan revisar los términos durante la instalación.
- **[MENOR]** Corregidas rutas de iconos para el modo producción.

### Mejorado
- Simplificado el instalador `build/installer.nsh` removiendo configuraciones redundantes.
- Agregada limpieza automática del proceso backend al cerrar la aplicación principal de Electron.
